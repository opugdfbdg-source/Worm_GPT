WormGPT - نسخة الملفات المسطحة

كل ملفات المشروع موجودة مباشرة في جذر الأرشيف، بدون مجلدات داخلية.

الرفع:
1) فك ضغط الأرشيف.
2) ارفع جميع الملفات الموجودة بجانب بعضها مباشرة إلى جذر الاستضافة أو مجلد الموقع.
3) يجب أن يكون index.html في الجذر.

الملفات المهمة:
- index.html: الواجهة.
- config.js: إعداد عنوان API (القيمة الأصلية فارغة ولم يتم اختراع عنوان بديل).
- prompt.js: إعدادات المساعد الأصلية.
- fonts.css وملفات .woff2: الخطوط المحلية.

تم تحديث مسارات الخطوط لتعمل من الجذر بعد فك الضغط. لم يتم تغيير منطق طلبات الخدمات الخارجية أو مصادر الردود.

تنبيه: تشغيل المحادثات يعتمد على وجود API صالح؛ ملف config.js في المصدر يحتوي قيمة فارغة.
